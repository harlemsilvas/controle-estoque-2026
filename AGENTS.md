# Instruções de continuidade

- Ler `CODEX_CONTINUITY.md` e informar a TAG mais recente, estado confirmado e pendências ao retomar.
- Usar a estrutura da main de controle-estoque-2026 como base oficial.
- Consultar `_referencias_locais/` somente quando necessário; preservar seus arquivos e não versioná-los.
- Nunca imprimir ou registrar valores de `.env`, senhas ou tokens.
- Preservar alterações locais; conferir Git antes de editar.
- Separar migração local de produção Windows/IIS e SQL Server; não executar migrations ou deploy sem solicitação.
- Atualizar a continuidade após alterações materiais e distinguir registros históricos de verificações atuais.
